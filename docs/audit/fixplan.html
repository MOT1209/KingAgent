خطة الإصلاح: ١٣ دفعة، مرتّبة بما تُغلقه لا بما يسهل

الترتيب هنا مقصود. الدفعة الأولى ليست الأسهل، بل أكبر عدد من النتائج الحرجة مقابل أقل عدد من الملفات. واحرص على دفعة واحدة: إصلاح U6 هو حذف كلمة واحدة من attributeFilter ويقفل حلقة إطار كاملة.

النتائج المُغطّاة 90 من 90 الملفات الممسوكة 96 ملفًا أصغر دفعة ملف واحد · أكبرها 23 ملفًا الاعتماد على نتائج حسّاسة: لا شيء

الجهد مقابل الأثر

المحور الأفقي عدد الملفات الممسوكة، العمودي الرأسي حجم ما يُغلق من التقرير. كل نقطة دفعة واحدة.

الزاويةUpper-left هي أفضل مكان في الصورة

P4 (تسريبات الـ renderer) وP5 (مسارات التخطيط) وP8 (حارس الوعد): الملفات القليلة، الأثر الكبير. P4 تحديدًا يحذف ملفًا كاملًا (session-sources.mjs، ١٦٠ سطرًا مستورد من لا شيء) ويضيف dispose() لمسار واحد. إن كان وقتك ضيقًا، هذا أعلى عائد لكل ساعة في التقرير كله.

النواة الحرجة: كيف تُصلَح فعليًا

ثلاث نتائج حرجة تحتاج أكثر من سطر. هذا ما يقترحه التقرير بالتحديد.

S1 + S2 + S3 إغلاق باب التنفيذ

النمط واحد: resolveSpawnProgram يستبدل الأسماء المجرّدة فقط، فأي مسار مطلق يمرّ. الحل: قائمة سماح صريحة تُبنى عبر knownBin(id) — وهي القيمة التي في الـ main بالفعل ولا يحتاج الـ renderer أن يخترعها. 

// قبل: أي مسار يمرّ
if (!s || !/^[A-Za-z][\w.-]*$/.test(s)) return s;

// بعد: لا مسار مطلق من الـ renderer إطلاقًا
function allowlistedProgram(id) {
  const bin = knownBin(id);              // من ذاكرة الـ main
  if (!bin) throw new Error('unknown agent');
  return bin;
}
// وقبلها: if (!DEMO) return { ok:false }  للقناة التجريبية

C1 + C9 تنشيط الدفاعات الميتة

intest اختبارا متحرّكان ولا يُستدعيان. الحل: انقل الفحص إلى داخل مسار الجلب بحيث لا يمكن تجاوزه، بدل الاعتماد على أن المزوّد يلتزم بالعقد. 

// SourceManager.fetchFull — قبل أي مقبس
const addrs = await dns.lookup(host, {all:true});
for (const a of addrs) screenResolvedAddress(a, opts);
// وعلى كل قفزة
maxRedirects: MAX_REDIRECTS,
redirect: (from,to) => screenRedirect(from,to,opts);

// synthesizer.write —Findings
`FINDINGS:\n${wrapUntrusted(body)}`

C2 ميزانية تُنفَّذ فعلًا

الحوكمة مبنية ومختبَرة؛ noteUsage() فقط بلا أي موضع استدعاء إنتاجي. لا تحتاج بناء نظام ميزانية — تحتاج استدعاء دالة موجودة. 

// ai/provider.js — الغلاف الوحيد
async function generate(req) {
  const r = await inner(req);
  governor.noteUsage(req.agentId, {
    tokens: r.usage.total_tokens,
    cost: r.usage.total_cost,
    tasks: 0,
  });
  return r;
}

//   ⇒ sweep() غير فارغ

اقتراحات التطوير — بعد الإصلاح

ما سبق يصلح ما كسر. هذا ما يجعل المشروع أفضل بعد أن يكون سليمًا. الأولوية ليست بالأرقام — هي بما يجعل الاستخدام اليومي ممكنًا.

ترتيب مقترح لستة أسابيع

خطة قابلة للتنفيذ على جدول أسبوعي. لا تتطلب أي منها قرارًا معماريًا جديدًا.
الأسبوعالدفعاتما يُغلقشرط الإنجاز
١ P4 · P5 · P13 تسريبات، مسارات تخطيط، كود ميت — ١٣ نتيجة U6: احذف 'style' من attributeFilter. session-sources.mjs محذوف.
٢ P10 · P8 Keychain، openExternal، حارس الوعد — ١٢ نتيجة لا استعلام متزامن على خيط الرئيسية. كل await في معالج نقر داخل catch.
٣–٤ P1 كل مسارات تنفيذ الـ renderer — ٧ نتائج حرجة لا spawn ولا rm -rf بمسار من الـ renderer. trustedRoot على كل معالج مسار.
٤–٥ P6 · P7 وصول لوحة المفاتيح، حواريات، حصر تركيز — ١٠ نتائج كل ورقة لها role="dialog" وحصر تركيز. لا استدعاء confirm() أصلي.
٥–٦ P2 العربية و RTL — ٥ نتائج حرجة dir="rtl" معمول. خط عربي مرفق. بوابة lint ترفض الانحدار.
متوازٍ P3 · P9 الدفاعات الميتة، مهلة المزوّد، إلغاء حقيقي — ٦ نتائج حرجة اختبار يحتجز: تشغيل ٦٠٠ ألف توكن ⇒ sweep() غير فارغ.
متوازٍ P11 · P12 تباين، حركة، رموز design، سوم في المنسّق — ١٠ نتائج كل رمز نصّي ≥ ٤٫٥:١ في كل سمة. _tasks له سقف.

ملاحظة على الجدولة: الدفعتان P1 و P2 هما الأثقل (٣٢ ملفًا) لكنهما أيضًا الوحيدتان اللتان تلمسان سلوكًا مرئيًا — أي أنها تُحدث فرقًا مرئيًا الآن. إن كان الوقت ضيقًا، نفّذ الأسبوع ١ كاملًا (يضع الأساس الصحيح) ثم قفز إلى P1 قبل P2.
