# تقرير تدقيق KingAgent

تدقيق كامل لكود KingAgent، بالعربية، على شكل صفحات HTML مستقلة بلا أي تبعية.

- **النسخة**: 0.5.6 · **الالتزام**: `457cc45` · **تاريخ القياس**: 2026-09-30
- **النتائج**: ٩٠ نتيجة — ١١ حرجة · ٢٩ عالية · ٣٣ متوسطة · ١٧ منخفضة
- **الأسلوب**: قياس لا انطباع. كل رقم مُقاس وكل نتيجة لها موقع `ملف:سطر`.

## الصفحات

| الصفحة | المحتوى |
| --- | --- |
| `index.html` | نظرة عامة · توزيع النتائج · الدفاعات التي لا يمكن أن تعمل |
| `findings.html` | كل النتائج الـ٩٠، قابلة للبحث والتصفية بالخطورة والطبقة |
| `interface.html` | **الواجهة والعربية** · RTL · الوصول · التباين |
| `security.html` | **الأمان** · أسطح الثقة · الثغرات · التبعيات |
| `performance.html` | **الأداء** · مسارات التخطيط · 处理 الأخطاء · التسريبات |
| `quality.html` | **الجودة** · التغطية · الثغرات في الأدوات · فجوات الاختبار |
| `fixplan.html` | **خطة الإصلاح** · ١٣ دفعة · خارطة طريق · إعادة الإنتاج |

افتح `index.html` من القرص مباشرة. لا خادم، ولا شبكة، ولا خطوة بناء.

## البنية

```
data.js                   مصدر الحقيقة الوحيد — كل رقم وكل نتيجة
audit.css                 الورقة المشتركة، منطقية الاتجاه بالكامل
audit.js                  الرسوم (SVG يدويًا) + التصفية + مساعدات النتائج
render-audit-shots.mjs    الأتمتة: يتحقق من كل صفحة ويصوّرها
shots/                    المخرجات
```

`data.js` هو السبب في أن رقمًا لا يستطيع أن يتناقض بين صفحتين: لا تكرر
الأرقام في HTML. النتيجة مكتوبة مرة واحدة، والصفحات تقرأها.

## إعادة التوليد

```bash
npm run audit          # يتحقق من الصفحات السبع ويصوّرها
npm run audit:full     # مع شرائح للصفحات الطويلة
```

السكربت **يتحقّق قبل أن يكتب**: كل صفحة تُفحص على العقد المتوقّع وعدد الرسوم
وعدد النتائج واتجاه المستند. السبب مباشر — صفحة يرمي فيها سكربتها خطأً
<em>لا تزال تُصوَّر</em>، تُصوَّر كورقة فارغة، وهذه لا يمكن تمييزها عن تصميم
مقصود. التحقق يجعلك تكتشف الخطأ بدل أن تراجع صورة مقنعة.

## الرسوم

كلها SVG مبنية يدويًا. لا مكتبة رسوم، ولا CDN، ولا `require`. السبب نفسه
الذي يجعل `docs/media/render-social-card.mjs` يستخدم Electron: المستودع
يملك المتصفح أصلًا، فلا داعي لإضافة تبعية من أجل التقاط صورة.

الرسوم تُحسب بإحداثيات LTR وتُعرض داخل صفحة RTL. هذا مقصود ومعلّق عليه في
`audit.js` — في صفحة عربية، `text-anchor="end"` ينقلب إلى اليسار، فيخرج
عنوان العمود عن الإطار. فالنصوص العربية تُرسم بـ `direction: rtl` مع
`text-anchor: "start"`، والقياس يبقى LTR.

## قراءة الرقم

`٩٠` ليست رقمًا مخيفًا بحد ذاته. الرقم المهم هو **أين**:

- **٥١** في الواجهة، لأن دعم العربية غائب تمامًا لا جزئيًا
- **١٢ ملفًا** في العملية الرئيسية بتغطية صفر، اثنان منها يحملان نتائج حرجة
- **٤** دفاعات أمنية مكتوبة ومختبَرة وبلا أي موضع استدعاء إنتاجي
- **١** متغيّر عام قابل للتعديل في ٢٨٬٦١٣ سطرًا — انضباط نادر يُبنى عليه كل شيء

البوابات الآلية كلها تمر: ٢٢١٦ اختبارًا، صفر أخطاء lint، تغطية ٨٦٪.
هذه الصفحة (`quality.html`) تشرح لماذا لا تتعارض هذه الجملة مع ما سبق.
